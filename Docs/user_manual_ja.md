# Fast AO Baker 使い方ガイド

**Fast AO Baker** は、Unity エディタ上で 3D メッシュのアンビエントオクルージョン（AO / 影）テクスチャを GPU で超高速にベイク・生成するツールです。  
BVH（境界ボリューム階層）による加速構造と Compute Shader、エッジ保存型デノイズ（À-trous / SVGF）を組み合わせることで、Substance Painter 級の滑らかで高精細な影マップを Unity 内だけで素早く作成できます。

---

## 画面構成

上から順に、次の要素で構成されています。

1. **トップバー** — ツール名・バージョン表示・最新版確認・言語切り替え・マニュアル・メニュー
2. **対象カード** — ベイクする GameObject（ターゲット）と影を落とす追加オブジェクト（遮蔽物）
3. **基本AO設定カード** — 解像度・UVチャンネル・自己/相互オクルージョン・低リソースモード、および「詳細設定」
4. **影のノイズ除去カード** — SVGFエッジ保存型デノイズのON/OFFおよび平滑化パラメータ
5. **仕上げ設定カード** — UV隙間の穴埋め（ダイレーション）・影の色・ガウシアンぼかし
6. **出力ドック** — 保存先フォルダ・上書き設定・テクスチャ結合設定
7. **ベイク実行ボタン / キャンセルボタン** と **ステータスバー**

ウィンドウを小さくリサイズしても、中央のカード群がスクロールし、トップバーと下部（出力ドック・ベイクボタン・ステータスバー）は常に画面内に固定表示されます。

---

## 起動方法

Unity 上部メニューの **`dennokoworks` > `Fast AO Baker`** を選択するとウィンドウが開きます。

---

## 基本の流れ

1. Hierarchy でベイクしたいオブジェクトを選択した状態でウィンドウを開く（または「ターゲット」カードにドラッグ＆ドロップ）
2. 基本AO設定カードで **解像度**（既定 2048）を確認
3. 必要に応じて「詳細設定」の **影の広がり (Max Distance)** などをモデルの大きさに合わせて調整
4. **`ベイク`** ボタンを押す
5. 計算完了後、指定フォルダ（またはモデルのテクスチャ付近）にテクスチャが保存され、Project ビューで自動的にハイライト選択されます

### 2. 対象カード（ターゲット / 遮蔽物メッシュ）

ベイク対象とする GameObject と、影を落とす追加のオブジェクトを指定します。

#### ターゲット (TARGET)
ここに登録された GameObject ごとに、それぞれのUVに合わせてAOテクスチャがベイク・出力されます。  
※ `MeshFilter` または `SkinnedMeshRenderer` を持っている必要があります。

- **自動登録**: ターゲットが空の状態でウィンドウを開くと、Hierarchy で選択中の GameObject が自動で入ります。
- **ドラッグ＆ドロップ**: Hierarchy から GameObject をカード上にドラッグすると青くハイライトされ、ドロップで追加できます。
- **`選択から追加`**: Hierarchy で選んでいる GameObject を一覧に追加します。
- **`すべて外す`**: 登録されたターゲットをすべて解除します。
- **個別解除 (`×`)**: 各行の右端にある `×` ボタンで個別に解除できます。
- **メッシュ情報表示**: 検出されたメッシュ数および利用可能な UV 情報を表示します。
- **Read/Write 警告 & `有効にする` ボタン**: メッシュの `Read/Write Enabled` がオフになっていると警告が表示されます。**`有効にする`** を押すとモデルのインポート設定を自動で書き換えて即座に有効化できます。

#### 遮蔽物メッシュ (OCCLUDER MESHES)
ターゲットに対して影を落とす「周囲のオブジェクト」（背景、小物、衣装パーツなど）を登録します。  
遮蔽物として登録されたオブジェクト自身にはテクスチャは出力されません。

---

### 3. 基本AO設定カード

AOベイクの基本パラメータとレイ制御を設定します。カード右上の **`↺`** で、このカードの設定のみを初期値に戻せます。

| 設定項目 | 説明 | 変更による影響 |
|---|---|---|
| **出力解像度**<br>`(Resolution)` | 生成されるテクスチャの解像度（128 / 256 / 512 / 1024 / 2048 / 4096）。既定は 2048。 | **▲増やす**: 細部まで鮮明な影になりますが、ベイク時間とファイルサイズが増加します。<br>※内部拡大ではなく指定解像度でネイティブ計算されます。 |
| **UV チャンネル**<br>`(UV Channel)` | ベイクに使用するメッシュの UV チャンネル（Auto / UV0 〜 UV7）。既定は Auto。 | **Auto**: 最初に見つかった有効な UV セットを自動選択します。<br>**明示指定**: ライトマップ用 UV1 など特定の UV にベイクしたい場合に指定します（メッシュに存在しない UV は警告が表示されます）。 |
| **自分自身の影**<br>`(Self Occlusion)` | メッシュ自身が自分に落とす影（服のシワ、装飾品の凹凸など）を計算します。既定は ON。 | 複雑な形状のオブジェクトを立体的に見せるための基本機能です。 |
| **お互いの影**<br>`(Mutual Occlusion)` | 登録された遮蔽物メッシュや他のターゲット同士が落とす影を計算します。既定は ON。 | 重ね着した衣装や隣接するアクセサリーからの影を焼き込みたい場合に有効です。 |
| **低リソースモード**<br>`(Low Resource Mode)` | 計算を細かく分割して GPU にディスパッチします。既定は OFF。 | **ON**: GPU ドライバのタイムアウト (TDR) や Unity のクラッシュ・PC フリーズを防ぎます。時間は長くなりますが、極端な高ポリゴンモデルや低スペック環境でも安全に動作します。 |

#### 詳細設定 (▶ 詳細)
カード下部の **`▶ 詳細`** をクリックすると展開されます。折りたたんでいる間は、初期値から変更された項目が小さなチップ（例: `広がり 0.50m`）として見出し横に表示されます。

| 設定項目 | 説明 | 変更による影響 |
|---|---|---|
| **影の細かさ**<br>`(Ray Count)` | 1テクセルあたりに飛ばすサンプリングレイの本数（16 〜 256、既定 64）。 | **▲増やす**: レイ数が増えて影が滑らかかつ正確になります（時間は長くなります）。<br>後段のデノイズと組み合わせることで、標準値の 64 でも十分な品質が得られます。 |
| **影の広がり**<br>`(Max Distance)` | 影レイが届く最大距離（0.01m 〜 5.0m、既定 0.3m）。 | **▲増やす**: 遠くの遮蔽物まで考慮され、広く柔らかい陰影になります。<br>**▼減らす**: 狭い隙間や角だけに局所的な影がつきます。<br>※モデル全体のスケール感に合わせて調整してください。 |
| **レイの浮き**<br>`(Ray Bias)` | メッシュ表面からレイを発射するオフセット距離（0.0001m 〜 0.05m、既定 0.002m）。 | **▲増やす**: メッシュ表面に黒い斑点状の自己遮蔽ノイズ（アクネ）が出る場合に解消できます。<br>**▼減らす**: 接地部や溝の密着した影が浮いてしまう場合に下げます。 |
| **裏面を無視**<br>`(Ignore Backfaces)` | ポリゴンの裏面による遮蔽判定を無視します。既定は ON。 | **ON**: 閉じたメッシュの内部による不要な黒ずみを防ぎます。<br>**OFF**: 薄い両面描画の布や髪の毛など、裏面からも影を落としたい場合にオフにします。 |

### 4. 影のノイズ除去カード (SHADOW SMOOTHING)

エッジ保存型（À-trous / SVGF）アルゴリズムにより、GPU レイトレーシング特有のザラつきを瞬時に滑らかにします。  
見出しのトグルで機能全体の ON/OFF を切り替えられます（OFF時は設定が折りたたまれます）。右上の **`↺`** で初期値に戻せます。

| 設定項目 | 説明 | 変更による影響 |
|---|---|---|
| **滑らかさ**<br>`(Iterations)` | デノイズフィルターの反復適用回数（1 〜 5、既定 3）。 | **▲増やす**: ザラつきが強く消え滑らかになります。上げすぎると非常に細かな影が薄くなる場合があります。 |
| **形状の維持**<br>`(Sigma Pos)` | 3D空間上の位置の差に対するエッジ保持の感度（0.1 〜 5.0、既定 1.0）。 | **▼減らす**: 角や段差など、形状の境界をよりシャープに保持します。<br>**▲増やす**: 多少の段差をまたいで滑らかにぼかします。 |
| **カーブの維持**<br>`(Sigma Nrm)` | 法線の向き（角度差）に対するエッジ保持の感度（0.05 〜 2.0、既定 0.5）。 | **▲増やす**: なだらかな曲面を均一に保ちやすくなります。<br>**▼減らす**: カクカクした稜線やハードエッジをまたいだブラーを防ぎます。 |
| **影のコントラスト**<br>`(Sigma Lum)` | 影の明るさ（輝度差）に対するエッジ保持の感度（0.01 〜 1.0、既定 0.1）。 | **▼減らす**: 明暗の差がはっきりした強いコントラストを保持します。<br>**▲増やす**: 影の濃淡差をなじませて均一化します。 |

---

### 5. 仕上げ設定カード (FINISHING TOUCHES)

ベイク後のポストプロセス（エッジ拡張・影の色・ぼかし）を行います。右上の **`↺`** で初期値に戻せます。

| 設定項目 | 説明 | 変更による影響 |
|---|---|---|
| **隙間の穴埋め**<br>`(Dilation)` | UVアイランド境界から外側へ影ピクセルを引き伸ばすピクセル幅（0 〜 64px、既定 16px）。 | UV境界の隙間を埋めることで、Mipmap生成時や遠景表示時にテクスチャの切れ目に黒い線（シーム）が出るのを完全に防ぎます。JFA（Jump Flood Algorithm）により超高速に処理されます。 |
| **影の色**<br>`(Shadow Color)` | 最も暗い部分に乗算される影の色（既定: 黒 `#000000`）。 | 乗算ブレンドを前提とした環境光カラーの作成や、暖色・寒色にトーンを寄せた影マップを作成できます。 |
| **ぼかし**<br>`(Gaussian Blur)` | 最終結果に全体的なガウシアンぼかしをかけるトグル（既定: OFF）。 | オンにすると、全体がふわっとした拡散感のある柔らかな影に仕上がります。 |
| **ぼかしの強さ**<br>`(Blur Intensity)` | ぼかしの反復回数（1 〜 10、既定 1）。 | ぼかしをかける回数を増やし、より強いソフトフォーカス効果を与えます。 |

---

### 6. 出力ドック (OUTPUT)

テクスチャの保存先とファイル上書き設定を行います。

- **出力先 (Output)**:
  - 空欄（または **`自動`** ボタンを押した状態）の場合、元のモデルのテクスチャが置かれているフォルダの近くに `BakedAO` フォルダを自動作成して保存します。
  - **`選択…`** ボタンを押すと、プロジェクト内の任意のフォルダ（`Assets/...` 配下）を手動で指定できます。
- **既存ファイルを上書き (Overwrite Existing)**:
  - **ON**: 既に同名のテクスチャが存在する場合、上書き保存します。
  - **OFF**: 既存ファイルがある場合、ファイル名に自動で連番（`ファイル名 1.png` 等）を付与して新規保存します。
- **1枚のテクスチャにまとめる (Combine into Single Texture)**:
  - **ON**: 登録されているすべてのターゲットメッシュ（およびサブメッシュ）を1枚のテクスチャにまとめてベイク・出力します。複数のメッシュが領域の重ならない共通の UV レイアウトを持っている場合に使用してください。複数メッシュ結合時は `BakedAO_<先頭メッシュ名>_Combined.png` として保存されます。
  - **OFF（既定）**: ターゲットメッシュおよびサブメッシュ（マテリアル）ごとに個別のテクスチャとして出力します。

---

### 7. フッター & ステータスバー

- **`ベイク` ボタン**: ベイク処理を開始します。実行中は進捗状況（例: `ベイク中… 60%`）が表示されます。ターゲットが未登録の場合は無効化されます。
- **`キャンセル` ボタン**: 実行中に押すことで、ベイク処理を安全に中断します。
- **ステータスバー (DennokoStatus)**:
  - 「待機中」「メッシュ準備中」「BVH構築中」「AOトレース中」「デノイズ中」「ベイク完了」など、現在の状態を詳細に通知します。
  - 完了時には保存先のファイルパスが表示され、Project ウィンドウで生成アセットが自動的に選択されます。

## よくある質問 (Q&A)

#### Q: ベイク中に Unity がフリーズしたり落ちたりします。
**A:** 高ポリゴンなメッシュ（数十万〜数百万ポリゴン）や GPU の負荷耐性によって、ドライバの TDR（タイムアウト検出）が発生している可能性があります。  
基本AO設定カードの **「低リソースモード」** をオンにして実行してください。

#### Q: 影が全体的に真っ黒（または薄すぎて真っ白）になります。
**A:** 「詳細設定」の **「影の広がり (Max Distance)」** がモデルのスケールに対して合っていない可能性があります。  
キャラクターや小物など小さなオブジェクトの場合は `0.1m 〜 0.3m` 程度、建造物や部屋全体などの大きなオブジェクトの場合は `1.0m 〜 3.0m` など、モデルのサイズに合わせて調整してください。

#### Q: メッシュの表面に黒い斑点や縞模様のノイズが出ます。
**A:** レイが自身のポリゴン表面と干渉する「自己遮蔽ノイズ」です。  
「詳細設定」の **「レイの浮き (Bias)」** を少し上げてください（例: `0.002` → `0.005`）。

#### Q: モデルのテクスチャの継ぎ目（シーム）に黒い線が出ます。
**A:** 仕上げ設定の **「隙間の穴埋め (Dilation)」** の値を増やしてください（例: `16` → `32`）。UVアイランドの余白を十分に埋めることでシームのチラつきを防げます。

#### Q: ライトマップ用など UV0 以外の UV にベイクしたいです。
**A:** 基本AO設定カードの **「UVチャンネル」** ドロップダウンから、目的のチャンネル（`UV1` など）を指定してベイクしてください。
